# Dirección creativa

## Propósito

Demostrar capacidad para crear contenido visual y audiovisual a partir de un encargo concreto. Cada proyecto debe resolver un problema, desarrollar una habilidad y ofrecer una prueba visible del resultado.

## Perfil de dirección

Perfil ficticio inspirado en Steve Jobs. Es una herramienta de decisión creativa, no una representación histórica ni una atribución de palabras reales.

- Una idea dominante por pieza.
- La propuesta se entiende antes de explicar la técnica.
- Cada elemento tiene una función.
- Se selecciona por calidad y fidelidad al encargo.
- La complejidad crece con la capacidad demostrada.

## Estética

La identidad del sitio es minimalista, clara y 2D. No impone la estética de las obras. Cada proyecto puede requerir fotografía editorial, animación, realismo o experimentación.

Antes de producir cada nuevo proyecto se revisan referencias actuales de contenido con IA. Por cada referencia se registra fecha, enlace, recurso que interesa y motivo para usarlo. Una tendencia aporta un recurso; no sustituye el concepto ni garantiza impacto.

## Roles

Matías define los objetivos, participa en las decisiones y evalúa los resultados. El asistente desarrolla los conceptos, prepara los encargos, explica las decisiones y coordina las herramientas disponibles. Magnific se utiliza para las tareas de generación y edición que estén disponibles en la cuenta.

## Publicación

Las piezas conceptuales se presentan como proyectos personales. Solo se declaran resultados que puedan verificarse. El valor comercial propuesto se distingue del rendimiento medido.

Los prompts, referencias, correcciones y créditos se registran. La imagen final debe acompañarse de una explicación breve de la decisión central y la intervención de Matías.
